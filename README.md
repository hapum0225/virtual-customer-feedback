# 가상 고객 피드백 (virtual-customer-feedback) 🐜

**합성 페르소나로 "실제 고객에게 물어볼 질문"을 만드는 Claude Code 스킬입니다. 고객의 답을 아는 도구가 아닙니다.**

AI에게 "고객이 이걸 어떻게 볼까?"라고 물으면 그럴듯한 답이 나옵니다. 문제는 **3주 뒤에 그게 "실제로 들은 이야기"로 기억된다**는 것입니다. 이 스킬은 그 착각을 구조적으로 막습니다.

- 모든 논점·질문 줄에 **`(가상)`** 표시가 붙습니다 — 한 줄만 잘라 다른 문서에 붙여넣어도 표시가 따라갑니다.
- 논점마다 **실제 고객에게 물어볼 검증 질문**이 따라붙습니다. 이게 진짜 산출물입니다.
- 가상 결과만으로는 **기능 채택·가격 확정·제작물 변경·"검증됨" 전환을 하지 못하게** 막혀 있습니다. 요청해도 거절합니다.

---

## 30초 요약 — 이렇게 나옵니다

```
합성 페르소나 카드 3건 · 실제 고객 0명 · 독립 표본 아님 · 결정 상태=보류
실행 ID=VCF-20260829-01 · 모드=M1 · 표본조건=전체|전체|전체|-|- · 선택 방식=순환(무작위 아님) · 별칭=P01,P02,P03 · 비신뢰 데이터=트리거 미감지
```

**논점 (M1 · 반응 논점) — 판(가상)**

| 판 | (가상) 논점 | 근거 | (가상) 전제 | 질문 |
|---|---|---|---|---|
| 🟢 | (가상) 미리 읽지 않아도 된다는 안내가 진입 문턱을 낮추는 방향으로 작동함 | [카드 단서: P01 관심사] | (가상) 참여를 막는 주된 요인이 준비 부담이다 | Q1 |
| ❌ | (가상) 신청 전에 장소를 알 수 없어 폼 앞에서 멈춤 | [모델 생성] | (가상) 신청 전에 이동 거리를 먼저 확인한다 | Q2 |
| ⬛ | (가상) 토요일 오전 고정이 루틴으로도 제약으로도 읽혀 갈림 | [카드 단서: P03 관심사] | (가상) 토요일 오전이 이미 다른 활동으로 차 있는지에 따라 갈린다 | Q3 |

**실제 고객에게 물을 검증 질문 — 2안 중 선택**

| # | 안 | (가상) 질문 | 누구에게 | 무엇으로 판정 | 어떻게 |
|---|---|---|---|---|---|
| 2 | a(권장) | (가상) 최근 3개월 안에 동네 모임을 신청한 적 있나요? 장소는 언제 아셨어요? | 최근 3개월 내 소모임 신청자 | 신청 **전에** 찾아봤다 → 일치 / 나중에 알아도 됐다 → 불일치 | 대화 |
| 2 | b | (가상) 지난 모집 문의 중 장소를 묻는 문의가 몇 건이었나요? | 운영 기록 | 장소 문의가 있으면 일치 | 기존 데이터 |

`"전부 a"` 또는 `"1a, 2b"`로 답하면 확정 질문지가 나옵니다.

## 설치

Claude Code 채팅에 아래를 **그대로 붙여넣으세요.**

```
https://github.com/hapum0225/virtual-customer-feedback 이 스킬을 사용할 수 있는 상태로 세팅해줘
```

또는 직접:

```bash
claude plugin marketplace add hapum0225/virtual-customer-feedback
claude plugin install virtual-customer-feedback@virtual-customer-feedback --scope user
```

설치 후 `/reload-plugins`를 실행하거나 Claude Code를 재시작하세요. 확인은 `/virtual-customer-feedback:virtual-customer-feedback`으로 합니다(플러그인 스킬은 `플러그인:스킬` 네임스페이스를 씁니다). 슬래시 없이 `가상 고객 피드백 돌려줘`라고 해도 열립니다.

> 자세한 설치·사용법은 **[docs/사용설명서.md](./docs/사용설명서.md)** 를 보세요. 처음이면 그 문서 하나만 읽으면 됩니다.

## 쓰는 법 (제일 짧은 형태)

```
가상 고객 피드백 돌려줘.
대상물=landing.md v1 / 알고 싶은 것=처음 보는 사람이 신청까지 갈지
```

모드·표본 조건은 안 적어도 됩니다 — 의도에서 알아서 고르고, 무엇을 골랐는지 출력에 적습니다.

## 5개 모드

| 모드 | 언제 | 출력 |
|---|---|---|
| **M1** 반응 논점 | 어떤 반응 축이 있는지 훑을 때 | 논점 3~6개 |
| **M2** 거부·이탈 이유 | "왜 안 쓰지?"를 좁힐 때 | 부정 축만, 확인 싼 순 |
| **M3** 두 안 대조 | A/B 중 어디서 갈리는지 | 갈리는 지점만 |
| **M4** 첫 경험 마찰 | 처음 접한 사람이 막히는 곳 | 단계별 막힘 |
| **M5** 검증 질문 설계 | 물어볼 것만 만들 때 | 질문지 (페르소나 안 뽑음) |

모드를 안 정해도 됩니다. 의도가 여러 개면 **여러 모드를 한 번에** 돌리고 표를 나눠 냅니다.

## 이 스킬이 하지 않는 것 (하드 룰)

| 요청해도 안 함 | 대신 |
|---|---|
| 기능 채택·폐기 결정 | 실제 고객에게 물을 검증 질문 |
| 가격 확정·추천 (숫자 판단) | 동일 |
| 제작물(코드·카피·디자인) 변경 | **변경 후보 목록** + 검증 질문 |
| 상태를 `검증됨`으로 전환 | `미검증(가상)` 유지 |

다시 요청해도, 다음 턴에 요청해도 같습니다. 막히는 것은 도구가 아니라 **가상 결과를 근거로 삼는 것 자체**입니다.

## 안전장치

- **경로 가드** — 현재 작업 폴더 밖, 프로젝트 규칙 파일이 금지한 폴더는 **읽기 전에** 중단합니다.
- **프롬프트 인젝션 방어** — 대상물·페르소나 카드·로그 안의 `시스템 지시:` 같은 문장은 전부 **데이터로만** 취급합니다. 발견하면 원문을 인용하고 생성을 멈춘 뒤, 사용자의 별도 재승인을 받습니다.
- **도구 잠금** — 스킬이 열린 턴에는 `Write`·`Edit`·`NotebookEdit`·`Bash`·`PowerShell`·`WebFetch`·`WebSearch`가 제거됩니다. 무엇이 잠기고 무엇이 안 잠기는지는 `SKILL.md` §1에 정확히 적혀 있습니다("어떤 파일도 못 고친다"고 말하지 않습니다 — 사실이 아니므로).
- **외부 점검 프롬프트** — 생성한 모델이 자기 출력을 점검하는 것은 검증이 아닙니다. 다른 세션·다른 모델에 붙여넣어 돌릴 점검 프롬프트가 스킬의 `references/output-contract.md` §8에 있습니다.

## 페르소나 팩

한국 성인 **합성 페르소나 40건**(연령 4구간 × 수도권/비수도권 8층 × 5건)이 들어 있습니다. NVIDIA의 `Nemotron-Personas-Korea`(CC BY 4.0)에서 선별·가공했습니다.

**표본 선택은 무작위가 아니라 순환(rotation)입니다.** 스크립트를 돌리지 않는 스킬이라 실행 중 난수를 만들 수 없기 때문입니다. 직전 실행 기록을 `log.md`에서 읽어 그다음 카드부터 뽑습니다 — 기록하지 않으면 매번 같은 3건이 나옵니다.

> ⚠️ **팩은 한국·만 19세 이상 성인 기준입니다.** 미성년·해외 고객에는 쓸 수 없습니다.
> ⚠️ **"개인정보 없음"은 검증된 사실이 아닙니다.** 데이터셋 카드에 그런 문장이 없습니다. 인명 치환은 정규식 기준이라 미검사 잔여 가능성이 있고, 별칭화는 익명화가 아닙니다. **쓰기 전에 [NOTICE.md](./NOTICE.md) §3을 반드시 읽으세요.**

## 검증 상태

- **정적 검토**: 규칙 문서의 상호 정합성을 외부 모델(Codex)로 점검 — 규칙 개정 시 29건, 공개 준비 시 5회에 걸쳐 19→7→14→13→5건 발견. 5차에서 **`disallowed-tools`가 실제로 적용되지 않는다**는 사실이 드러나 §1을 사실대로 다시 썼습니다.
- **런타임 시험**: 별도 세션에서 A군(정상)·C군(차단)·D1·G군 전량 실행 — 최종 실패 0건. **공개 저장소에서 설치→발동까지 실검증 완료**(2026-09-02). 시험 정의는 스킬의 `references/pilot-tests.md`.
- **출력 점검**: 생성된 출력을 §8 프롬프트로 외부 모델 점검 — "위반 없음".
- **미검증**: E군(인젝션)은 **현재 출력 양식으로 재시험하지 않았습니다.** 이전 양식에서는 E1~E5·E7이 통과했고 **E6는 그때도 미실시**입니다(`pilot-tests.md` §I). B군·D2~D5·F군도 이번 양식에서는 재시험하지 않았습니다. macOS/Linux는 문서 제공(실검증 전) — 개발·검증 환경은 Windows 11 / Claude Code 2.1.x.
- **본질적 미검증**: **이 스킬이 실제 고객 반응을 잘 예측하는지는 검증되지 않았습니다.** 그것을 재는 유일한 수단은 검증 질문을 실제로 물어보고 `log.md`에 후속 줄(`판정=일치|불일치|모름`)을 쌓는 것입니다.
